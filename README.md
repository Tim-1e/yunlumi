# Yunlumi · 云路觅

> 云海之上，群星沉睡。你是一缕名叫 **Lumi** 的光——沿着云路收集流光，点亮五座星宿，在天亮之前唤醒它们的灵兽。

一款纯前端的 **三维粒子飞行游戏**，WASD + 鼠标操控。画面里所有东西（云海、云塔、星空、银河、光点、风环、星辰、墨魇、五只灵兽、终幕巨花）都是用 Three.js 的 GPU 粒子实时生成和驱动的，没有用任何贴图、模型或音频文件。

名字的来历：**yun（云）+ lu（路 / 鹿）+ mi（觅）**，再加上 *lumi*（光）。

## 怎么玩

**目标**：在夜晚结束（倒计时归零）之前唤醒全部五座星宿：星鹿、云鲸、锦鲤、青鸾、昙花。

1. **集光**：沿着发光的“云路”飞行。靠近光点会自动把它吸过来；连续吸收能叠加连击倍率（最高 ×5），每吸一颗光点会按五声音阶响一个音，连起来就是一段旋律。你身后的彗尾长度就是你当前携带的光量。
2. **风环**：穿过云路上的风环可以瞬间加速，补充疾飞能量，连击 +3。
3. **点亮星辰**：带着 ≥ 8 光穿过一颗沉睡的星辰，就能点亮它，同时会有光从你的尾巴流进星辰，星座连线也会被逐笔画出来。
4. **唤醒灵兽**：一座星宿的星辰全部点亮后，粒子会从各颗星辰飞出，聚成这座星宿的灵兽（鹿会奔跑，鲸会摆尾喷水，锦鲤会摆动，青鸾会振翅，昙花会呼吸般开合），之后它会在天空中巡游。效果：
   - 获得一项**永久强化**（见下表）
   - 夜晚**延长 30 秒**
   - 灵兽会定期洒下光点，并**吞掉靠近它的墨魇**
   - 极光变强，云海被灵兽的颜色照亮
5. **墨魇**：墨色的粒子团，会追你，碰到就偷走你约 25% 的光。有两种办法对付它：
   - **绽光**（左键 / E）：花 4 光放出一圈冲击波，驱散半径内所有墨魇，云海也会被推出涟漪。
   - **冲刺**（右键 / Q）：免费，但有冷却。冲刺时可以直接穿过墨魇把它击散。
   被驱散的墨魇会把偷走的光全部吐出来，还会额外多给一些。
6. **探索惊喜**
   - **流星**：会不定期从你附近划过，用 Shift 疾飞追上去，奖励 +20 光和高分。
   - **月灯**：一共 7 盏，藏在云塔顶部、云海下面和最高的天顶。离得远时只有很淡的微光，飞近才会亮起来。
7. **终幕**：唤醒五灵之后，五只灵兽会一起环绕天空中心，一朵由 3.6 万粒子组成的彩虹昙花在夜空中绽放，同时放烟火。剩余的时间会换算成奖励分。

如果时间耗尽，天会亮，云海被染成金粉色，然后结算。结算会给出评级（S/A/B/C/D），最佳分数保存在 localStorage 里。

| 星宿 | 强化 |
| --- | --- |
| 星鹿 鹿 | 鹿角感应：吸光范围 +60% |
| 云鲸 鲸 | 鲸歌：绽光范围 +50%，消耗减半 |
| 锦鲤 鲤 | 每粒光价值翻倍 |
| 青鸾 鸾 | 疾飞能量 +60%，恢复更快 |
| 昙花 昙 | 冲刺冷却减半，连击窗口延长 |

### 操控

| 输入 | 作用 |
| --- | --- |
| 鼠标 | 转向（点击“起飞”后自动锁定指针） |
| W / S | 前进 / 减速后退 |
| A / D | 横移（镜头会随之侧倾） |
| 空格 / C（或 Z） | 上升 / 下降 |
| Shift | 疾飞（消耗能量，会自动恢复） |
| 左键 / E / F | 绽光 |
| 右键 / Q | 冲刺 |
| P / Esc | 暂停（Esc 会解除指针锁定，游戏随之自动暂停） |
| R | 在暂停或结算界面重新开始 |
| M | 静音 |
| \` | 显示帧率、像素比、特效粒子数 |

方向键也能代替 WASD。菜单里可以调画质、鼠标灵敏度、反转 Y 轴，这些设置会保存到本地。

## 运行

不需要构建步骤，也不需要安装依赖。用任意静态文件服务器托管本目录即可：

```bash
python3 -m http.server 8080          # 或：npx serve .   /  任意静态服务器
# 浏览器打开 http://localhost:8080/
```

> 不能直接双击用 `file://` 打开：浏览器不允许从 file:// 加载 ES Module 和 importmap。

**浏览器要求**：支持 WebGL2、ES Module 和 importmap 的现代桌面浏览器（Chrome / Edge 89+、Firefox 108+、Safari 16.4+）。游戏是为键盘和鼠标设计的，移动端能打开，但没有触控操作方案。

### 依赖与网络

| 依赖 | 版本 | 来源 |
| --- | --- | --- |
| three.js | **0.170.0**（固定版本） | `https://cdn.jsdelivr.net/npm/three@0.170.0/build/three.module.js`，写在 `index.html` 的 importmap 里 |

这是**唯一的运行时网络请求**。没有字体、图片、音频或统计脚本，也不需要后台或任何密钥。

如果想完全离线或自托管：

```bash
mkdir -p vendor
curl -L -o vendor/three.module.js https://cdn.jsdelivr.net/npm/three@0.170.0/build/three.module.js
# 然后把 index.html 里 importmap 的地址改成 "./vendor/three.module.js"
```

如果 CDN 无法访问，页面会显示中文错误说明，而不是一直黑屏（见 `index.html` 里的启动看门狗脚本）。

### 自检

```bash
node tests/selftest.mjs     # 或 npm test；需要 Node ≥ 18，没有其他依赖
```

这个脚本覆盖的是不依赖 DOM 和 three.js 的核心逻辑：

- 帧率无关：同样的输入，分别按 30 fps 和 144 fps 模拟 2 秒，位置和速度应该一致
- 指数阻尼、线段与点距离、线段穿圆盘的检测（用来防止高速飞行时“穿模”漏判）
- 飞行模型：巡航速度、疾飞、能量消耗与恢复、冲刺冷却、地板、边界、俯仰角限制
- 规则：连击与倍率、点亮消耗、星宿完成后加时并发放强化、偷光、绽光消耗、胜利与时间奖励、天亮只结算一次、评级
- 墨魇 AI：出生、追击、追太久会放弃、偷光后逃跑、溶解
- 五种灵兽点云：长度正确、没有 NaN、尺寸合理、部件数量
- 世界数据：连线索引合法、所有星辰都在可飞行范围内、云路与月灯的位置合法

## 技术说明

### 结构

```
index.html            页面骨架、HUD、菜单、importmap、启动看门狗
style.css             UI 样式（只用系统字体，不发起网络请求）
src/main.js           渲染器、状态机（菜单/游戏/暂停/终幕/天亮/结算）、主循环、碰撞与玩法串联、镜头
src/core/*.js         纯逻辑，可以在 Node 里测试：math、flight（飞行模型）、rules（经济/计分）、gloomAI、shapes（灵兽点云雕塑）、data（关卡布局）
src/gfx/common.js     共享的 uniform 和粒子着色器片段（点大小按世界单位换算、绽光波、HSV）
src/world/sky.js      天穹（渐变、月亮、极光、黎明）、星空与粒子银河
src/world/clouds.js   约 7.2 万粒子的云海和云塔：会被玩家分开、被绽光推出涟漪、被灵兽照亮
src/world/roads.js    云路光点（含自由漂浮的光点池）和风环
src/world/constellations.js  星辰、连线，灵兽 Creature（粒子从星辰聚合成形、按部件做骨骼式动画）、终幕巨花
src/world/gloom.js    墨魇的渲染（墨色用 alpha 混合，火花和眼睛用加色混合；每只墨魇的状态通过 uniform 数组传给 GPU）
src/world/events.js   流星、月灯
src/fx/bursts.js      9000 粒子的 CPU 特效池（环形缓冲区）
src/fx/comet.js       玩家彗星（核心、光晕、环绕的小粒子）、用光量决定长度的螺旋彗尾、速度尘
src/audio.js          WebAudio 程序化合成：氛围铺底、风声（跟随速度）、墨魇低鸣（跟随距离）、五声音阶的收集旋律、FM 钟声、琶音
src/input.js          键鼠输入，指针锁定和降级方案
src/hud.js            HUD 刷新（只在值变化时写 DOM）、屏幕边缘的目标指引箭头
```

### 关键处理

- **帧率无关**：飞行对恒定加速度和指数阻尼做的是解析积分（有测试验证）；所有平滑都用 `1 - exp(-λ·dt)`；`dt` 上限 50 ms。碰撞（光点、星辰、墨魇、流星、月灯）都按“上一帧位置到这一帧位置的线段”检测，风环用“线段穿圆盘”检测，所以低帧率加高速也不会漏判。
- **窗口大小变化**：在 `resize` 事件里重设渲染尺寸、像素比和相机宽高比；点精灵的大小每帧根据当前画布高度和 FOV 重新换算，所以改窗口大小或缩放页面后，粒子的观感保持一致。
- **指针锁定、暂停、重玩**：
  - 失去指针锁定（Esc）、切到别的标签页、按 P，都会暂停，世界冻结、声音挂起。
  - 点“继续”会重新请求锁定，锁定成功后才恢复游戏。Chrome 在按 Esc 后约 1 秒内会拒绝再次锁定，这种情况不会被当成失败，只会提示“再点一次”。
  - 如果真的无法锁定（例如在沙盒 iframe 里），连续失败两次后自动切换到无锁模式（直接用鼠标移动转向，按 P 暂停）。
  - 在暂停和结算界面按 R 可以完整重置一局（光点、风环、星辰、灵兽、墨魇、特效、计时全部归位）。
  - 鼠标偶尔会出现异常大的位移，单个事件的位移会被限制在 ±250。

### 性能策略

- 所有东西都是 `THREE.Points` 加自定义着色器，不写深度、不排序，能在着色器里算的动画都放在 GPU 上算（云海涟漪、灵兽动画和聚合成形、墨魇旋涡、星辰光柱、连线描绘、速度尘的循环）。
- CPU 每帧只更新三类缓冲：约 2600 个光点、9000 个特效粒子、约 1300 个彩尾粒子。墨魇、星辰、连线、风环、月灯只通过 uniform 数组传状态，不重新上传几何体。
- **画质档位**：云海和灵兽的点云在生成时打乱了顺序，所以用 `drawRange` 只画前面一部分，就能均匀地减少粒子数（高 100% / 中 62% / 低 38%）；不同档位的像素比上限分别是 2 / 1.5 / 1。“自动”档根据设备类型和 CPU 核数来选。
- **动态分辨率**：游戏中每 1.5 秒统计一次平均帧时间。超过 22 ms 就降低像素比（最低到 ×0.55），低于 17.5 ms 再慢慢恢复。
- 对点精灵的屏幕尺寸设了上限，镜头近处的云粒子会淡出，避免整屏都是大块的过度绘制。
- 不用后处理和泛光，“发光”效果完全靠加色混合和高斯形的点精灵来做。

### 可调参数

- 飞行手感：`src/core/flight.js` 里的 `FLIGHT`
- 夜晚时长、点亮消耗、计分：`src/core/rules.js` 里的 `RULES`
- 墨魇的感知范围和速度：`src/core/gloomAI.js` 里的 `GLOOM`
- 墨魇数量随时间增长的曲线：`src/main.js` 里的 `gloomTarget()`
- 星宿的位置、形状、强化内容：`src/core/data.js`
